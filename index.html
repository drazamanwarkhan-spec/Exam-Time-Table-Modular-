Auto Seating

Each course's students are kept together as one block. A course can fill a whole column, but the same course will never occupy two consecutive columns — a gap column (or a different course) is always inserted in between, so left/right neighbours never sit the same exam. Pattern: Course A | Course B | Course A | Course B … If only one course remains for a room, it skips a gap col then continues. Set Seats per Column to control how many students sit in each column, and Max Courses per Room to cap how many different courses can share one room in a session. Drag a column's header (the small labeled strip above each column) to move or swap that whole column with another column — in the same room or a different room.

👥 Program Groups for Joint Seating

Groups seat their programs together in the same room(s). Within a group, courses are interleaved column-by-column so a course never sits in two consecutive columns — a gap column (or a different course) always separates two blocks of the same course, while a room can still hold multiple courses side by side. Optionally pin a group to specific room(s) (in priority order) and set a rows-per-column override — otherwise it uses whichever rooms are free and the global "Seats per Column"/"Max Courses per Room" settings below. If a group has more students than its rooms hold, the overflow spills into the next available room automatically.
➕ Create a new group
Click programs below to select them, then click Create Group. Only eligible exam programs are shown — excluded programs (MBA, MS, PhD, etc.) and lab courses are not listed.

Student/faculty clashes and daily-overloads also show manual move options below the auto-fix.
