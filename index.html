🔗 Exam Grouping Rules

Controls which courses the Auto Scheduler is required (or prefers) to place in the same session/day.
Course-wise grouping (selector at the top) — sections of the same course (same course code or same course name; spacing, dashes, case and “(Section A)” tags ignored) are scheduled in one session. Same department only keeps e.g. Functional English of BS-CS, BS-DS and BS-SE as separate exams that are scheduled independently. All departments merges them into one session. No grouping schedules every course on its own.
Seating never puts two courses with the same name in neighbouring columns, whichever option is chosen.

Auto Seating

Each course's students are kept together as one block. A course can fill a whole column, but the same course will never occupy two consecutive columns — a gap column (or a different course) is always inserted in between, so left/right neighbours never sit the same exam. Pattern: Course A | Course B | Course A | Course B … If only one course remains for a room, it skips a gap col then continues. Set Seats per Column to control how many students sit in each column, and Max Courses per Room to cap how many different courses can share one room in a session. Drag a column's header (the small labeled strip above each column) to move or swap that whole column with another column — in the same room or a different room. Full capacity: anyone the column pattern can't fit is seated in the remaining free seats of the rooms (never next to the same paper unless no other seat is left) instead of being parked. Manual drag works across sessions — you only get a notice if the student already has a class in that session.
📥 Seating reports: Day-wise puts each exam date on its own worksheet.

👥 Program Groups for Joint Seating

Groups seat their programs together in the same room(s). Within a group, courses are interleaved column-by-column so a course never sits in two consecutive columns — a gap column (or a different course) always separates two blocks of the same course, while a room can still hold multiple courses side by side. Optionally pin a group to specific room(s) (in priority order) and set a rows-per-column override — otherwise it uses whichever rooms are free and the global "Seats per Column"/"Max Courses per Room" settings below. If a group has more students than its rooms hold, the overflow spills into the next available room automatically.
➕ Create a new group
Click programs below to select them, then click Create Group. Only eligible exam programs are shown — excluded programs (MBA, MS, PhD, etc.) and lab courses are not listed.

📋 Unscheduled Papers — Manual Seating (0)

These papers have no exam session on the timetable yet. Pick a session for a paper below, then click 🅿️ Park to send all of its students to the Student Park for that session. Switch to the 🪑 Seating Rooms tab, choose the same session in the Student Park panel, and drag each parked student onto an empty seat -- exactly like clash students. Parking a paper here places its students into a room manually; it does not add the paper to the official timetable.

📋 Course-wise Seating Plan (exact DSU format)

Matches the official DHA Suffa University "SEATING PLAN" structure: University / Exam Title / SEATING PLAN header, then one Class + Course report at a time with Course Title, Session, Subject Teacher, Time, Date, followed by a S.No. / Reg No. / Name / Seating Plan (COL-x / ROW-y) / Room No. / Remarks table. Room No. is printed on every student row, and the PDF starts each course on a separate page. Edit the header text under Exam Sessions → Report Header.
